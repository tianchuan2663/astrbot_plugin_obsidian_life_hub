# Knowledge Base 插件历史迁移归档

本文件接收原 `knowledge-base` 中公开插件设计、发布与运维说明的历史上下文。v0.1.3 起，插件相关公开文档统一维护在独立仓库，知识库只保留私人运维凭据和个人知识内容。

## 已迁出类别

- 早期 PRD：社交机器人接入 Obsidian 第二大脑。
- 技术方案：AstrBot + writer + Git 同步链路。
- 插件设计：Inbox 插件、第二大脑生活助手、自然语言记录、固定触发词、财务 V2、计划系统、生活数据治理。
- 发布手册：Obsidian Life Hub 独立插件仓库、GitHub 发布、ECS 插件 ID 迁移。

## 仍留在知识库的内容

- 私有 ECS 登录公钥备份。
- 私有 ECS / Gitee / Docker 部署复现手册。
- AstrBot、Obsidian 同步等作为知识来源沉淀的 wiki 页面。

## 迁移原则

- 公开插件能力、配置、writer、安装和升级说明进入本仓库 `docs/`。
- 私人服务器地址、授权、公钥、运行配置和排障细节不进入公开插件仓库。
- 后续发布记录以 `CHANGELOG.md` 和 `docs/` 为准，知识库 `log.md` 只记录压缩摘要。
