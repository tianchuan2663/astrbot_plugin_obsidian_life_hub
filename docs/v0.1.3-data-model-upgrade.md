# Obsidian Life Hub v0.1.3 数据模型重构升级书

## 定位

v0.1.3 是正式发布前的破坏性数据模型升级，不兼容 v0.1.2 的旧 Markdown 结构。升级目标是让 Obsidian 中的生活记录更像长期可读的个人资料，而不是带有大量来源、sender_id、record_id 的调试日志。

## 新目录结构

```text
生活/
  财务/
    2026-05 财务.md
  健康/
    2026-05 健康.md
  日记/
    2026/
      2026-05/
        2026-05-29.md
  笔记/
    随想笔记/
      2026-05 随想笔记.md
    语录笔记/
      2026-05 语录笔记.md
  待办/
    备忘录/
      2026-05 备忘录.md
    计划/
      计划清单.md
  总结/
    晨报/
    日总结/
    周报/
    日记草稿/
```

## 表格模型

| 类型 | 文件 | 表头 |
|---|---|---|
| 财务 | `YYYY-MM 财务.md` | 日期、时间、类型、金额、类别、钱包/渠道、对象、状态、备注 |
| 健康 | `YYYY-MM 健康.md` | 日期、时间、类型、数值、单位、时长分钟、距离公里、状态、备注 |
| 随想 | `YYYY-MM 随想笔记.md` | 日期、内容、标签、备注 |
| 语录 | `YYYY-MM 语录笔记.md` | 日期、来源、作者/账号、语录、标签、一句话感想 |
| 备忘 | `YYYY-MM 备忘录.md` | 内容、截止日期、截止时间、状态、创建时间 |
| 计划 | `计划清单.md` | 计划内容、状态、开始时间、完成时间、创建时间、备注 |

计划清单固定分为 `短期计划`、`长期计划`、`其它计划` 三个表。备忘状态为 `未完成 / 已完成 / 已取消 / 已推迟 / 已过期`；计划状态为 `未开始 / 进行中 / 已完成 / 已推迟 / 已暂停 / 已取消`。

## 写入规则

- `备忘 / 备忘录 / DDL` 写入 `生活/待办/备忘录/`。
- `提醒我` 继续交给 AstrBot 原生未来任务，不写 Obsidian 备忘。
- `短期计划 / 长期计划` 显式进入对应计划表。
- 普通 `计划` 带日期或时间时进入短期计划；无日期时间时进入其它计划。
- `有空 / 空闲 / 以后` 只作为语气前缀剥离，不再自动推断为长期计划。

## Markdown 清洁规则

Obsidian 正文不再显示 `来源`、`sender_id`、`record_id`。插件需要的 `record_id` 写入 HTML 注释，例如：

```md
<!-- olh kind=finance;record_id=fin-20260529-demo -->
```

这样 Obsidian 阅读界面保持干净，同时仍支持撤销、修改和恢复索引。

## 升级策略

当前版本尚未正式面向外部用户发行，因此 v0.1.3 不保留旧路径和旧表格兼容。升级时建议：

1. 备份 ECS 插件目录、writer 目录和插件 `data/`。
2. 停止 AstrBot 与 writer。
3. 部署 v0.1.3 插件和 writer。
4. 清空旧 SQLite，启动后重建索引。
5. 用服务端模拟写入财务、健康、随想、语录、计划、备忘各一条。
6. 通过 QQ 真实消息复测 AstrBot 入口。

## 验收

- writer 测试通过。
- 插件核心测试通过。
- `生活/` 生成的新文件路径和表头符合本文。
- 晨报只展示天气和备忘。
- 今日总结展示备忘提醒、计划概览、财务简讯和日记草稿。
