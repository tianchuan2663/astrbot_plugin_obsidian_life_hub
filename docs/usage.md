# 使用手册

## 财务

```text
记账 午饭 18 元 支付宝
支出 咖啡 20 微信
收入 兼职 500 中国银行
借出 给张三 100 微信
借入 向李四 200
转账 微信转到中国银行300元
```

查询：

```text

本周财务
本月财务

```

修正：

```text
作废账目 午饭

撤销上一条
```


## 报告

```text
晨报
今日总结
日记草稿
周报
语录周精选
```

晨报保持轻量，只展示天气和当天备忘；今日总结展示待办提醒、短期计划概览、财务简讯和日记草稿；周报用于复盘财务、计划、生活片段和健康趋势。
